========================================
   Stock Tracker - 项目进度
   更新时间: 2026-09-02
========================================

=== 已完成 ===

1. 核心功能
   - 行情/K线/分钟K (akshare + 腾讯行情)
   - 自选股 + 预警系统 (价格/RSI/MACD/布林/跟踪止盈)
   - 站内聊天助手 (Assistant 页面 -> Spring Boot -> Python LLM)
   - 消息中心 (SSE 实时推送)
   - 股票名称展示 (搜索输入代码,其余位置显示名称)

2. 文件结构 (python-data-service/)
   - app.py                  # FastAPI 业务核心 (行情/搜索/量化/聊天, 端口 8000)
   - chat_handler.py         # 站内聊天助手核心 (意图路由: 行情/分析/历史/对比/闲聊)
   - llm_service.py          # DeepSeek LLM 客户端 (含 .env 自动加载)
   - quant_model.py          # 技术指标 + 量化模型
   - akshare_client.py       # 行情 API 客户端
   - prompts/                # LLM prompt 模板
   - start.ps1               # 一键启动脚本

3. 后端 (Spring Boot)
   - JWT 认证 + MySQL + Redis 缓存
   - 预警评估: 价格刷新事件驱动 (每 5 分钟)
   - 聊天链路: /api/v1/chat -> Python /api/v1/chat

4. 已修复问题
   - 股票代码前缀: 添加 bj 支持 (920xxx 北交所)
   - 股票名称: 全链路名称透传 (quote 接口返回名称)
   - K线图底部日期标签与缩放滑块重叠

=== 启动方式 ===

  # 1. MySQL + Redis (一次性)
  docker run -d --name stock-mysql -p 3306:3306 ^
    -e MYSQL_ROOT_PASSWORD=123456 -e MYSQL_DATABASE=stockdb mysql:8
  docker run -d --name stock-redis -p 6379:6379 redis:7-alpine

  # 2. Spring Boot (IDEA 启动 StocktrackerApplication)
  #    或命令行: cd stock-tracker && .\mvnw.cmd spring-boot:run

  # 3. Python (双击 start.ps1 或 .\start.ps1)

  # 4. 前端
  cd frontend && npm install && npm run dev
